# Геометрический тренажёр

Интерактивный сайт-тренажёр по презентации «Геометрический тренажёр»: задача о площади
треугольника по сторонам ортоцентрического треугольника (B₁C₁ = 5, A₁C₁ = 12, A₁B₁ = 13).

Что есть:
- вводная ветка «Выполнить чертёж к задаче» (два вопроса о свойствах ортоцентра + точный чертёж);
- способ 1 — по двум сторонам и углу между ними (с веткой через теорему синусов);
- способ 2 — с использованием теоремы Ван-Обеля;
- остальные 9 способов из презентации видны в списке как «Скоро»;
- счётчики неверных ответов и подсказок (общие в шапке и по каждому шагу),
  итоговая таблица по вопросам, процент ответов с первой попытки, время;
- прогресс сохраняется в браузере (localStorage) — после перезагрузки страница открывается на том же шаге.

Сайт полностью статический: без сборки и зависимостей (KaTeX лежит в `vendor/`).

## Публикация на Cloudflare Pages

1. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git → выбрать этот репозиторий.
2. Настройки сборки:
   - Framework preset: **None**
   - Build command: *(оставить пустым)*
   - Build output directory: **`geometry-trainer`**
3. Save and Deploy.

Либо без Git: Pages → Upload assets → загрузить содержимое папки `geometry-trainer`,
или через CLI:

```bash
npx wrangler pages deploy geometry-trainer --project-name geometry-trainer
```

## Локальный просмотр

```bash
cd geometry-trainer && python3 -m http.server 8000
```

## Как добавить способ

Все тексты, вопросы, варианты ответов и подсказки лежат в `js/data.js`:
1. В массиве `METHODS` укажите у нужного способа `active: true` и `start: "<id первого экрана>"`.
2. Добавьте в `NODES` экраны/вопросы этого способа (по образцу `m1_*` / `m2_*`): у вопроса — `method`,
   `section`, `step`, `options` (верный вариант — `ok: true`), `wrongDefault`, `hint`, `success`, `next`.
   Последний вопрос способа — `next: "again"` и `completes: "<id способа>"`.

Имена авторов — массив `AUTHORS` в конце `js/data.js`.
