# Цифровой двойник в Telegram

Нейросеть, которая учится на вашей переписке и сама отвечает людям в Telegram вашим стилем.
Всё бесплатно: открытая модель **Qwen2.5-7B-Instruct**, обучение в бесплатном Google Colab,
запуск у себя на компьютере через **Ollama**.

```
Экспорт Telegram ──► prepare_dataset.py ──► train.jsonl ──► Colab (дообучение) ──► twin.gguf
                                                                                     │
           Telegram ◄──── bot.py (ваш аккаунт) ◄──── Ollama (модель у вас на ПК) ◄───┘
```

## 1. Выгрузите переписку

Telegram Desktop → Настройки → Продвинутые настройки → **Экспорт данных из Telegram**:
- отметьте «Личные чаты»;
- медиа можно не выгружать;
- формат — **Машиночитаемый JSON**.

Получится папка с файлом `result.json`.

## 2. Подготовьте датасет

Нужен Python 3.10+.

```bash
cd twin
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python prepare_dataset.py "путь/к/result.json"
```

Получится `data/train.jsonl`: каждый пример — несколько последних реплик собеседника и ваш реальный ответ.
Скрипт берёт только личные чаты, пропускает пересланные сообщения и делит переписку на отдельные
разговоры по паузам больше 6 часов. Полезные флаги:

- `--exclude "Мама" "Начальник"` — не учиться на этих чатах;
- `--persona persona.txt` — факты о вас (где учитесь, работаете, город, интересы), чтобы модель
  меньше выдумывала. Если используете — укажите тот же файл в `PERSONA_FILE` для бота;
- `--name Андрей` — если имя определилось неправильно.

Чем больше ваших сообщений, тем лучше: от 1000 примеров уже заметен стиль, 5000+ — хорошо.

## 3. Дообучите модель (бесплатно, Google Colab)

1. Откройте [colab.research.google.com](https://colab.research.google.com) → Файл → Загрузить блокнот → `train_colab.ipynb`.
2. Среда выполнения → Сменить среду выполнения → **T4 GPU**.
3. Запускайте ячейки по порядку, на шаге загрузки выберите `data/train.jsonl`.

Обучение 5000 примеров занимает примерно час. В конце файл `.gguf` (~4.7 ГБ) копируется на ваш
Google Диск — скачайте его в папку `twin/` и переименуйте в `twin.gguf`.

> Слабый компьютер (меньше 8 ГБ ОЗУ)? В ноутбуке замените модель на `unsloth/Qwen2.5-3B-Instruct-bnb-4bit`.

## 4. Запустите модель у себя

Установите [Ollama](https://ollama.com/download), затем в папке `twin/`:

```bash
ollama create twin -f Modelfile
```

Создайте настройки и проверьте модель в консоли:

```bash
cp .env.example .env      # и заполните MY_NAME
python chat.py "Дима"     # вы пишете за Диму, модель отвечает за вас
```

Если ответы не похожи на вас — нужно больше данных или ещё одна эпоха обучения
(`num_train_epochs=2` в ноутбуке). Слишком «случайные» ответы — уменьшите `TEMPERATURE` в `.env`.

## 5. Запустите бота

1. Зайдите на [my.telegram.org](https://my.telegram.org) → API development tools, создайте приложение
   и впишите `API_ID` и `API_HASH` в `.env`.
2. Запустите:

   ```bash
   python bot.py
   ```

   При первом запуске Telegram попросит номер телефона и код — бот входит **в ваш аккаунт**
   (появится файл `twin.session`, никому его не передавайте: это доступ к аккаунту).

Как бот себя ведёт:
- отвечает только в личных сообщениях людям (не ботам, не в группах);
- ждёт `REPLY_DELAY` секунд после последнего сообщения, чтобы собеседник успел дописать;
- «печатает» и отправляет ответ несколькими сообщениями, как вы;
- если вы сами ответили в чат, пока он ждал, — молчит;
- `WHITELIST` — отвечать только этим людям, `BLACKLIST` — никогда не отвечать этим.

Управление — пишите себе в «Избранное»: `/twin off`, `/twin on`, `/twin status`.

Бот работает, пока включён компьютер с Ollama и `bot.py`. Для работы 24/7 бесплатно можно
использовать Oracle Cloud Always Free (ARM, до 24 ГБ ОЗУ) — модель там работает на процессоре.

## Важно

- **Модель не знает, что происходит в вашей жизни сейчас**, и может уверенно пообещать что-то от вашего
  имени («да, приду в 7»). Начните с `WHITELIST` из пары друзей и посмотрите, как она справляется.
- Честнее предупредить близких, что иногда отвечает бот.
- Не добавляйте в обучение рабочие и чувствительные чаты (`--exclude`): в датасете и на Google Диске
  окажется переписка других людей.
- Telegram разрешает автоматизацию личного аккаунта через API, но за массовые или спамные рассылки
  аккаунт могут ограничить.
- `.env`, `*.session`, `data/` и `*.gguf` исключены из git — не публикуйте их.
