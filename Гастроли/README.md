# БД «Гастроли» — вариант 12

Папку держать целиком: `posters/` должна лежать рядом с `Гастроли.accdb` (постеры трупп).

## Что внутри `Гастроли.accdb`

**Таблицы (лаб. 1)**
- `ТеатральныеТруппы` — шифр труппы (ключ), название театра, город, количество человек, количество спектаклей, постер (путь к картинке).
- `КонцертныеЗалы` — шифр зала (ключ), город, адрес, количество мест, стоимость одного билета.
- `Выступления` — шифр труппы, шифр зала, название спектакля, дата, время, количество проданных билетов. Ключ — (шифр зала, дата, время).
- **Дополнительно:** `КатегорииМест` — шифр зала, категория мест (ложа/партер/амфитеатр/бельэтаж/балкон), ряды с/по, коэффициент.
  Цена билета = стоимость билета зала × коэффициент. Связана с `КонцертныеЗалы` одной дополнительной связью по `ШифрЗала`.

**Связи:** Труппы → Выступления, Залы → Выступления, Залы → КатегорииМест (обеспечение целостности, каскадное обновление).

**Запросы (лаб. 2)** — 27 штук: на выборку, параметрические, с вычисляемыми полями, итоговые, 2 перекрёстных,
на обновление, добавление и удаление. SQL всех запросов — в `Запросы_SQL.txt`.

## Формы (лаб. 3) — один раз запустить макрос

1. Открыть `Гастроли.accdb`, нажать «Включить содержимое».
2. `Alt+F11` → File → Import File… → `modGastroli.bas`.
3. Встать курсором в процедуру `CreateGastroliForms` и нажать `F5`.

Создаются формы: «Главное меню» (кнопочная, открывается при запуске), «Театральные труппы» (с постером и
подчинённой таблицей выступлений), «Концертные залы» (с подчинёнными «Категории мест» и «Афиша зала»), «Выступления».
Если какой-то запрос сломается — процедура `RecreateGastroliQueries` в том же модуле пересоздаёт все запросы.
