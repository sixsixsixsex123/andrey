# БД «Гастроли» — вариант 12

Всё в одном файле `Гастроли.accdb`. Лабы 1 и 2 в нём уже сделаны, лабу 3 (формы) делаешь сам мышкой по инструкции ниже (~15 минут).

## Лаба 1 — таблицы и связи (готово)

База — это несколько табличек, как в Excel, только связанных между собой.

| Таблица | Что хранит | Поля |
|---|---|---|
| ТеатральныеТруппы | театры, которые ездят на гастроли | Шифр труппы (ключ), Название театра, Город, Количество человек, Количество спектаклей, Постер |
| КонцертныеЗалы | залы, где они выступают | Шифр зала (ключ), Город, Адрес, Количество мест, Стоимость одного билета |
| Выступления | какой театр, в каком зале, когда что играл | Код выступления (ключ, счётчик), Шифр труппы, Шифр зала, Название спектакля, Дата, Время, Продано билетов |
| КатегорииМест (доп. задание) | цена зависит от места: партер ×1,5, амфитеатр ×1,0, балкон ×0,6 | Код категории (ключ), Шифр зала, Категория мест, Коэффициент |

Связи (Работа с базами данных → Схема данных), все «один-ко-многим»:
- ТеатральныеТруппы → Выступления (по шифру труппы)
- КонцертныеЗалы → Выступления (по шифру зала)
- КонцертныеЗалы → КатегорииМест (по шифру зала) — это и есть «одна дополнительная связь».

Постер — поле «объект OLE», пустое. Чтобы вставить картинку: правой кнопкой по ячейке → «Вставить объект» → «Создать из файла».

## Лаба 2 — 20 запросов (готово)

- 01–02 — простая выборка (просто показать данные);
- 03–07 — параметрические (Access спрашивает, например, город);
- 08–10 — с вычисляемым полем (выручка = билеты × цена, свободные места, цена по категории);
- 11–14 — итоговые (посчитать, сложить, среднее, самое популярное);
- 15 — перекрёстный (таблица «театр × город»);
- 16–20 — сервисные (изменить цену, поднять цены на 10 %, добавить труппу/выступление, удалить выступление).

SQL любого запроса: открыть запрос → Вид → Режим SQL.

## Лаба 3 — формы (делаешь сам)

**Простые формы (Мастер форм), 3 штуки:**
1. Создание → Мастер форм.
2. Выбрать таблицу `ТеатральныеТруппы`, нажать `>>` (все поля) → Далее.
3. «В один столбец» → Далее → имя «Театральные труппы» → Готово.
4. Повторить для `КонцертныеЗалы` (форма «Концертные залы») и `Выступления` (форма «Выступления»).

**Кнопки на этих формах:** правой кнопкой по форме → Конструктор → на ленте «Кнопка» → нарисовать на форме →
«Переходы по записям» → «Предыдущая запись». Так же «Следующая запись». И третья кнопка:
«Работа с формой» → «Закрыть форму». Сохранить.

**Главная кнопочная форма (Конструктор):**
1. Создание → Конструктор форм.
2. «Надпись» → написать «Гастроли».
3. «Кнопка» → «Работа с формой» → «Открыть форму» → «Театральные труппы» → текст «Театральные труппы» → Готово.
4. Так же кнопки для «Концертные залы» и «Выступления».
5. Кнопка «Приложение» → «Выйти из приложения».
6. Сохранить как «Главное меню».

**Чтобы меню открывалось само:** Файл → Параметры → Текущая база данных → «Форма просмотра» → «Главное меню».
